"# ICT1222 Mini Project - Database Management System

## Project Structure

```
ict1222-mini-project/
├── docs/
│   ├── data-requirements.md      # Data requirements documentation
│   ├── er-diagram.png            # Entity-Relationship diagram
│   └── relational-mapping.png    # Relational schema mapping
├── sql/
│   ├── 01_schema.sql             # DDL - table creation
│   ├── 02_users.sql              # MySQL user accounts
│   ├── 03_sample_data.sql        # INSERT statements
│   ├── views/
│   │   ├── attendance_views.sql  # Attendance-related views
│   │   └── marks_views.sql       # Marks-related views
│   └── procedures/
│       ├── attendance_procs.sql  # Attendance stored procedures
│       └── marks_procs.sql       # Marks stored procedures
├── report/
│   └── final_report.docx         # Project report
└── README.md
```

## Setup Instructions

1. Create the database schema using `sql/01_schema.sql`
2. Set up user accounts with `sql/02_users.sql`
3. Load sample data using `sql/03_sample_data.sql`
4. Create views from the `sql/views/` directory
5. Create stored procedures from the `sql/procedures/` directory
